# ☁️ Galgotias Cloud Computing Club

<p>Build. Deploy. Scale. Repeat. 🚀</p>

## About

The Galgotias Cloud Computing Club is a student community focused on
cloud computing, hands-on learning, projects, certifications, and
industry-oriented skills.

## Technologies

- AWS
- Microsoft Azure
- Google Cloud
- DevOps
- Cloud Security

## Activities

- Hands-on labs
- Workshops
- Hackathons
- Certification sessions
- Networking

## Goal

To help students move from learning cloud concepts to building and
deploying real-world applications.

🚧 Currently under development.
